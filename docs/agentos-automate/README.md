# AgentOS - Automate

Troubleshooting articles for the **AgentOS - Automate** pod live here, organized into
subfolders by `section` (created automatically by `generate_articles.py`
as cases are drafted — nothing to set up manually).

This folder maps 1:1 to a single shared Contentstack entry for this pod
(the "AgentOS - Automate Troubleshooting Guides" FAQ page) — see
`pipeline/pod_entry_map.json` for the entry UID. Each article published
here becomes one FAQ (question/answer) appended into that entry's matching
category, not a separate standalone entry.
