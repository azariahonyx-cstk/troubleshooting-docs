# TSO

Troubleshooting articles for the **TSO** pod live here, organized into
subfolders by `section` (created automatically by `generate_articles.py`
as cases are drafted — nothing to set up manually).

This folder maps 1:1 to a single shared Contentstack entry for this pod
(the "TSO Troubleshooting Guides" FAQ page) — see
`pipeline/pod_entry_map.json` for the entry UID once it's been seeded.
Each article published here becomes one FAQ (question/answer) appended
into that entry's matching category, not a separate standalone entry.
